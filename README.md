# 이세계 편의점

> 판타지 마을에서 마법 편의점을 운영하는 1인칭 경영 시뮬레이션 게임

![이세계 편의점 타이틀 화면](title.png)

고블린, 오크, 드워프, 모험가, 마법사, 엘프 등 다양한 손님을 맞이하고 상품을 판매하며 상점을 성장시키는 Unreal Engine 팀 프로젝트입니다.

상품 발주와 진열, 계산, 제조, 배달을 관리하고, 날씨와 뉴스에 따라 달라지는 수요에 대응합니다. 영업으로 얻은 자금과 경험치를 활용해 새로운 상품과 시설을 해금하고 직원을 고용할 수 있습니다.

## 게임 플레이

1. **영업 준비** — 상품을 발주하고 매대에 진열하며 판매 가격을 설정합니다.
2. **영업 시작** — 간판과 상호작용해 손님을 맞이합니다.
3. **매장 운영** — 상품 계산과 재고 보충, 제조, 배달 주문을 처리하고 도둑을 제압합니다.
4. **마감 및 정산** — 하루 영업을 마치고 매출·지출·평판을 확인합니다.
5. **상점 성장** — 새로운 콘텐츠를 해금하고 다음 날 영업을 준비합니다.

상점을 운영하며 귀환에 필요한 재료를 모으고, 엔딩 조건을 달성하는 것이 최종 목표입니다.

## 저장 및 불러오기

- 타이틀에서 **3개 슬롯** 중 하나를 선택해 새 게임을 시작하거나 이어할 수 있습니다.
- 마감 활동 단계 진입 시 자동 저장하며, 그 전에 잠자기를 진행하면 해당 시점에 저장합니다.
- 불러오면 저장한 날의 마감 활동 상태로 재개합니다.
- 자금·상점 성장·상품·시설 배치·발주·날씨·콘텐츠 진행 등 주요 상태를 저장합니다.
- 손님과 직원의 진행 중 작업은 그대로 복원하지 않습니다.
- 에디터의 저장 파일은 `Saved/SaveGames/`에 생성됩니다.
- 현재 저장 버전과 다른 파일은 불러올 수 없습니다.
